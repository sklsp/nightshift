# Items for the hello run

## Add a farewell function

Add a `farewell(name)` function to `hello/__init__.py`. It returns "goodbye, <name>" with one space after the comma and keeps the existing greet function untouched.

## Test the farewell function

Add a test in `tests/test_hello.py` that calls `farewell("world")` and asserts it equals "goodbye, world". Run the tests from the repo root.

## Document the package

Update the module docstring in `hello/__init__.py` so it names both functions: greet and farewell.
